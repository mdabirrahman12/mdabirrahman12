#  DevConf 2026 – Conference Landing Page

##  Project Overview

DevConf 2026 is a responsive landing page for a developer conference. It presents the event's speakers, ticket packages, and daily schedule in a clean, modern layout. The project was built as part of an assignment.

##  Technologies Used

- **HTML5** – page structure
- **CSS3** – styling and layout (Flexbox / Grid)
- **Google Fonts (Inter)** – typography

## ✨ Key Features

- **Hero Banner** – "Code. Connect. Create" headline with a Register Now button
- **Meet the Speakers** – speaker photos, topics, names, and roles
- **Pricing Section** – Standard ($399), Pro ($749), and Team ($5,999) packages
- **Experience DevConf 2026** – schedule cards (Keynote, Workshops, Startup Showcase, Networking)
- **Navigation Bar** – Speakers, Schedule, Tracks, Venue, and Blog links
- **Footer** – social icons (GitHub, LinkedIn, X) and copyright notice
- **Responsive Design** – works on mobile, tablet, and desktop

## 📦 Dependencies

This project has no npm packages or frameworks. It uses only one external resource:

| Resource | Purpose |
|---|---|
| [Google Fonts – Inter](https://fonts.google.com/specimen/Inter) | Website font |

> An internet connection is required for the font to load.
